# Recuperación Datafast después de perder el proceso
Revisión 3b0c799e2168e55649ed6b621f5dde11143582be. PostgreSQL 17.11, GHC 9.6.6, esquema completo de 258 migraciones. Ejecución local con dos procesos Haskell secuenciales y un controlador Python. El primero creó el intento, respaldó la base, aplicó la confirmación sintética con recordVerifiedPaymentOrReconcile y terminó. El controlador restauró el respaldo. El segundo arrancó con la conexión local y leyó el vínculo exclusivamente desde la base restaurada. Ninguna confirmación pasó entre los procesos. El laboratorio eliminó la base al finalizar.

El primer proceso dejó 1 checkout pagado por 12515 centavos. Después de restaurar, el segundo encontró el vínculo Datafast y probó loadBoundProviderPayment y enqueueProviderQueries. La búsqueda rechazó el vínculo, la cola recibió 0 consultas y quedaron 0 checkouts pagados. Repetido con bandera sandbox habilitada y queryRecoveryReady=True. El fixture crea el vínculo Datafast pero no registra una operación durable de consulta Datafast. La llamada directa a enqueueProviderQueries también exige una operación elegible. En el código, providerQueryWorkerTickWith solo programa PlaceToPay y PayPhone. No se lanzó el worker completo. El handler de tickets tiene una ruta de consulta ante una solicitud con identificador y resourcePath asociados. No se invocó ese handler ni una fuente externa o simulada del proveedor.

El resultado negativo corresponde a recuperación autónoma de este intento y respaldo. Para el caso en que el respaldo ya contiene un checkout enlazado, la corrección propuesta es registrar y descubrir intentos Datafast pendientes y consultar su estado por el identificador y ruta guardados; validar la respuesta antes de invocar el escritor canónico. Si el intento también se creó después del respaldo, se requiere además una fuente de descubrimiento durable independiente del respaldo.

Para reproducir con el entorno del ensayo, sitúe el checkout en pg-replay-src, copie este directorio como durable-lab junto al checkout y use replay-tools/root para los paquetes Debian extraídos. Desde el directorio padre ejecute bash durable-lab/compile.sh y python3 durable-lab/run.py.
