# RSVP visual evidence

The PNG files in this directory are generated by the desktop Chromium journey in
`e2e/web/event-rsvp-sharing.spec.mjs`. The test runs the production web bundle against
intercepted, explicitly fictional API responses; it does not call production, social networks,
or payment providers. It captures the public event after the authoritative RSVP response and
the profile activity feed after navigation.

Regenerate from the repository root with:

```sh
npx playwright test e2e/web/event-rsvp-sharing.spec.mjs --project=chromium-desktop
```

The same run attaches the serious/critical axe results to the Playwright report.
